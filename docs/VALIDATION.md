# 0.2.1 プレビュー版の検証範囲

2026-11-05、Windows x64向けのプレビュー版です。

0.2.1ではZIPを新しいフォルダーへ展開し、空の保存領域からGUIの初回起動・GPU/メモリ/ディスク検出・推奨モデルの表示・ダウンロード開始を確認しました。モデル取得の完了、範囲翻訳・音声翻訳までの通し検証は未完了です。

以下は0.2.0の実装時に行った検査です。0.2.1では保存領域の分離機能と、アプリ/拡張機能の翻訳アイコンを追加しました。

- Rustの自動検査52件、ASRサイドカーのPython検査9件が成功しました。Clippyは警告なし、GUIと初期設定CLIのreleaseビルドが成功しました。
- Windows PowerShell 5.1で初期設定の診断モードと、音声環境の3構成の計画モードを確認しました。計画モードはダウンロード・インストールを開始しません。
- ローカルHTTPを使い、途中再開、Range応答、ハッシュ不一致、中止、ZIP内の不正パス、未完了モデルを既存の選択へ上書きしないことを検査しました。
- 容量の模擬データでCPU、NVIDIA、Vulkan、低メモリ、使用中GPU、空き容量不明を確認しました。実PCの検出結果も取得しました。全モデルを実際に取得・比較したものではありません。
- Claude Opus 5.5が変更前4画面と変更後6画面を確認しました。文字・配色・状態表示・初回準備を改善し、追加指摘のチェックボックスと中止表示も修正しました。
- 実アプリと同じeguiの画面コードを、1280×880および860×620でPNGへ描画しました。実際のデスクトップ操作を伴う検証ではありません。

新しいWindows利用環境でのモデル取得から翻訳までの通し検証、任意ASR環境の新規導入、全14種類の速度比較、AMD/Intel GPUでの推論、150%表示スケールは未検証です。範囲選択の実操作とYouTube拡張の実ブラウザー接続も、この版の追加検証では完了していません。

既存の開発環境では以前の版で、PLaMo 2B Q4_K_Mの翻訳、Windows OCR、Qwen3-ASRの推論、両系統の並行処理、音声取得の開始・停止を確認しています。その結果を、新しい導入経路全体の検証済みという扱いにはしていません。

推奨は現在の容量に基づく初期選択です。すべてのPCでの最速・最高品質や、音声翻訳が常にリアルタイムへ追いつくことを保証するものではありません。保存先、別のモデル、CPU実行へ変更できます。

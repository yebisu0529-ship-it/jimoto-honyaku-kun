# YouTube字幕をローカル翻訳する

1. 地元翻訳くんを起動し、「設定と接続」で接続キーをコピーします。アプリの「YouTube字幕を使う」をオンにします。
2. Chromeの `chrome://extensions` またはEdgeの `edge://extensions` を開き、開発者モードをオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、この `extension` フォルダーを選びます。インストールや権限設定は手動で行ってください。
4. 拡張機能のアイコンを押して設定を開き、トークンを貼り付けて「保存」→「接続確認」を押します。
5. YouTubeページを再読み込みします。動画のCCをオンにし、歯車→字幕→英語など、翻訳元の字幕を選択します。アプリ側で必要な翻訳先を選びます。

表示されている字幕だけを、約300msの更新待ちで送信します。画面上の字幕が消えたとき、一時停止、シーク、動画の変更時にはクリア状態も通知します。`www.youtube.com` と `m.youtube.com` の通常ページが対象です。字幕のない動画、他サイトの埋め込み、字幕DOMが異なる画面は対象外です。YouTubeの表示変更によって動作しなくなる場合があります。

送信先は `http://127.0.0.1:17862` 固定です。`POST /caption` へ `{text, video_id, position, paused, epoch}` を送り、`GET /health` で接続を確認します。両方で `X-Plamo-Token` ヘッダーを使用します。字幕本文の上限は4000文字です。古い通信は中止し、再送キューは作りません。続く字幕の原文は翻訳アプリで訳文を置換表示する想定です。

Cookie、ログイン情報、字幕ファイルのダウンロードや外部の音声認識は使いません。トークンはブラウザーの拡張機能ローカル領域に保存されます。「トークンを削除」で削除できます。同期保存はしません。

接続できない場合は、アプリの連携開始状態とトークンを確認してください。アプリを再起動してトークンが変わった場合は保存し直します。複数のYouTubeタブで同時に再生すると字幕が競合するため、翻訳する動画は一つにしてください。実ブラウザーでの動作検証は別途必要です。

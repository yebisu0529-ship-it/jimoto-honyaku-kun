# YouTube字幕をローカル翻訳する

1. Talk風Live翻訳を起動し、「⋯ その他」→「YouTube字幕の接続」を開きます。「接続キーをコピー」を押します。この画面には、拡張機能とつながったか、接続キーが違うか、字幕が届いているかも出ます。
2. Chromeの `chrome://extensions` またはEdgeの `edge://extensions` を開き、開発者モードをオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、この `extension` フォルダーを選びます。インストールや権限設定は手動で行ってください。
4. 拡張機能のアイコンを押して設定を開き、接続キーを貼り付けて「保存」→「接続確認」を押します。
5. YouTubeページを再読み込みします。動画のCCをオンにし、歯車→字幕→英語など、翻訳元の字幕を選択します。アプリ側で必要な翻訳先を選びます。アプリのチャットで「● 聞く」を押すと、字幕の翻訳が始まります（「入力の切り替え」が「自動（字幕を優先）」か「YouTube字幕だけ」のとき）。

このフォルダーのファイルを新しくしたときは、`chrome://extensions`（Edgeは `edge://extensions`）で、この拡張機能の再読み込みボタンを押してください。そのあと、開いているYouTubeのページも再読み込みしてください。

表示されている字幕だけを、約300msの更新待ちで送信します。画面上の字幕が消えたとき、一時停止、シーク、動画の変更時にはクリア状態も通知します。`www.youtube.com` と `m.youtube.com` の通常ページが対象です。字幕のない動画、他サイトの埋め込み、字幕DOMが異なる画面は対象外です。YouTubeの表示変更によって動作しなくなる場合があります。YouTubeの窓を最小化したときなどは、YouTubeが字幕の表示を止め、最後の字幕を画面に残します（音の出ている動画を別のタブにしたときは、表示が続きます）。ページが隠れていて、動画が5秒進んでも字幕が変わらないときは、その字幕を送らず、クリア状態を通知します。アプリの「入力の切り替え」が「自動（字幕を優先）」なら、そのあいだはPC音声を訳します。字幕が動き出すと、また送ります。

送信先は `http://127.0.0.1:17862` 固定です。`POST /caption` へ `{text, video_id, position, paused, epoch}` を送り、`GET /health` で接続を確認します。両方で `X-Plamo-Token` ヘッダーを使用します。字幕本文の上限は4000文字です。古い通信は中止し、再送キューは作りません。続く字幕の原文は翻訳アプリで訳文を置換表示する想定です。

Cookie、ログイン情報、字幕ファイルのダウンロードや外部の音声認識は使いません。接続キーはブラウザーの拡張機能ローカル領域に保存されます。「接続キーを削除」で削除できます。同期保存はしません。

接続できない場合は、Talk風Live翻訳が起動しているかと、貼り付けた接続キーを確かめてください。接続キーは、ふだんはアプリを再起動しても変わりません。複数のYouTubeタブで同時に再生すると字幕が競合するため、翻訳する動画は一つにしてください。2026年11月8日に、Chromium 156と実際のYouTube動画（英語の自動字幕）で、字幕の受け渡しと翻訳を確かめました（docs/VALIDATION.md）。Google ChromeとMicrosoft Edgeの本体では、まだ確かめていません。

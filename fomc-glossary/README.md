# 金融（FOMC記者会見）の用語集の効果（2026-11-09）

設定の「金融（FOMC記者会見）の用語を入れる」で入る30語を、本物の字幕で、入れる前と後で訳し比べた記録です。訳文は PLaMo 3 Translate の出力です（translated by PLaMo）。

## 比べ方

- 原文：2026年10月28日のFOMC記者会見（YouTube `hs8YWtNQQ40`）の英語の自動字幕です。確認用データ（`M:\JimotoDemo-20261105\data\sessions`）の記録から、時間が重ならない21段落（9,831字）を使いました。take1（9〜143秒）の5段落と、ほかの記録の16段落（154〜1011秒、冒頭の声明と質疑）です。`corpus.json` にあります。
- 訳し方：アプリのライブ翻訳（`src/document.rs` の `document_translate`）と同じ順で、ライブラリの関数を呼ぶ小さなプログラムです（`harness/`）。言いよどみを除き、直前の3段落（1,600字まで）の原文と訳を文脈に付け、敬体・英語から日本語で1回目を訳します。そのあと、画面に出す「やさしい日本語」へ2回目で書き直します。用語集は1回目だけに渡ります（アプリと同じ）。
- サーバー：アプリと同じ引数のllama-server（llama.cpp b12119 CUDA）を、別のポート17870で、1回ごとに起動し直しました（`runner.py`）。起動し直さないと、前の回のプロンプトのキャッシュで訳が変わります。同じ条件で2回訳すと、21段落のうち一致したのは10段落でした。起動し直すと、2回とも21段落すべてが一致しました。
- アプリと同じ訳になるか：take1の5段落では、1回目の訳が、録画のときにアプリが出した訳と5段落とも1文字も違いませんでした。画面に出した訳は4段落が同じで、1段落は1か所の言い回しだけが違いました。
- モデル：確認用データにある 8B と 0.8B（どちらも Q4_K_M）です。2Bは確認用データになく、ダウンロードが要るので試していません。

## 変わった文

用語集を入れると、プロンプトが変わるので、用語のない文も言い回しが変わります。変わった文の一覧は次のファイルです（`-` が前、`+` が後）。

- 8B：1回目 `diff-8b-standard.txt`（121文のうち54文）、画面 `diff-8b-shown.txt`
- 0.8B：1回目 `diff-08b-standard.txt`（120文のうち61文）、画面 `diff-08b-shown.txt`

用語のほかに、意味が変わったものを全部読んで分けました。

- 良くなった
  - 8B：画面（やさしい日本語）の「委員会は物価が変わらないようにします」（price stability の取り違え）が、「委員会は物価を安定させます」になりました。「In support of the Federal Reserve's dual mandate」を、前は別の文として訳していましたが、「連邦準備制度の2つの責務を支持し、…据え置くことを決定しました」とつながりました。ほかに「ご清聴いただき」「（記者の）報道をここ1、2日読んでいただければ」「政策決定を行ったり…することは想定していない」が原文に近くなりました。
  - 0.8B：「この金融医療」が「この金融政策」に、「発言のない会議」が「声明が発表されない会合」になりました。
- 悪くなった
  - 8B：「全体的な金融環境は引き締まっていますが…「タイトである」と表現することは控えます」が、「…「引き締まっている」と表現することは控えます」になり、tighter と tight の違いが消えました。画面では、#0 が「連邦準備制度の2つの役割を認めました」（1回目は「支持し」で正しい）になり、#13 の記者の質問が「すでにふさわしいのかもしれません」と言い切りになりました。
  - 0.8B：「地政学的な動向などが一因となり不確実性は依然として残る」が「地政学的な動向に一因とならずには不透明感が残って」と崩れ、「1つの質問ルール」の問いが「1点だけ質問をされたのですが、ルールは聞いていませんでしたか」になりました。画面では「雇用の増加は労働力の増加に連動」が「働いている人の数が増えることは、働く人の数が増えることにつながっています」と同じことの繰り返しになりました。
- 残りは、意味の変わらない言い回しの違いです。

## FOMCの言い回しの文（`probes.json`）

この動画に出てこない語を確かめるため、FOMCの声明や記者会見の言い方に合わせた英文44件を書き、文脈なしで1件ずつ訳しました（字幕ではありません）。結果は `runs/*-probe-*.jsonl` と `probe-diff.txt` です。用語集なしでは、次の誤りが出ました。用語集を入れると、0.8Bの「the dots → 点」のほかは直りました。

- 8B：federal funds rate → 連邦資金金利、Chair Powell → パウエル委員長、Governor Waller → ウォラー知事、a larger cut → より大幅な削減、discount rate → 割引率、accommodative → 寛容、The mandate → 権限、Federal Reserve → 連邦準備制度理事会、balance sheet → 貸借対照表
- 0.8B：Board of Governors → 取締役会、restrictive → 規制、balance sheet runoff → 貸借対照表の流出、the dots → 点、headline inflation → 英語のまま、payroll gains → 給与の伸び、anchored → 堅調、holding rates steady → 保有率を一定に保つ

## 入れなかった語と文脈

- 文脈の行（例：「米国の中央銀行である連邦準備制度（FRB）の、連邦公開市場委員会（FOMC）のあとに開かれる議長の記者会見です。」）：用語集がないときは、委員長→議長、知事→理事、割引率→公定歩合などを直しました。用語集があると、これらは用語集だけで直り、文脈を足しても用語は変わりませんでした。0.8Bでは「委員会は物価の安定を実現します」が「…について報告します」になるなど、悪くなる文が出ました。日本語の短い文と英語の文でも同じでした（`runs/*-corpus-V3C*.jsonl`。この比べ方は、30語に `maximum employment` を加えた31語の版で行いました）。
- 分数（`and 3/4 = .75` など）：8Bでは「3 and 3/4 to 4%」が「3.75～4%」になりましたが、0.8Bでは「3.5～4%」と違う数になりました。金利の数が変わるのは「3と3/4」より悪いので入れていません。
- `cut = 利下げ`、`rate cut = 利下げ`：0.8Bで「Governor Waller dissented in favor of a larger cut.」（より大きな利下げを求めて反対した）を「ウォラー理事は、利上げ幅の拡大に反対しました」と、逆の意味に訳しました。どちらの行もないと「より大幅な利下げに賛成しました」です。
- `maximum employment = 雇用の最大化`：8Bで、話し手の「full employment」まで「雇用の最大化」に変えました。

## FOMC以外の文（`general.json`）

用語集を入れたままほかの話題を訳したときの確認です。「椅子を引いて」「石油埋蔵量」「マスク着用義務」「錨を下ろしました」「厳しすぎます」は、用語集があっても変わりませんでした。「Governor Newsom」は、8Bと0.8Bの両方で「ニューサム理事」になりました（正しくは知事）。ボタンを押したときに、ほかの話題では行を消すよう伝えています。

## 時間

1回目の1段落の時間（21段落の中央値）は、用語集なし（`A2`）と入る30語（`PRESET`）を続けて測ると、8Bで640msから685ms、0.8Bで156msから160msでした。2回目（やさしい日本語）は変わりません。用語集の分だけプロンプトが長くなるためと考えます（用語集はプロンプトで段落ごとの文脈の後ろにあり、前の回のキャッシュが使えません）。

## 同じ結果になることの確認

- 用語集なしを時間をおいて2回（`A` と `A2`）：8Bも0.8Bも21段落すべて同じ。
- 30語の表を手で書いた回（`V4`）と、アプリに入った表を使った回（`PRESET`、`harness --preset`）：両方のモデルで、21段落・44文・8文すべて同じ。

## ファイル

- `corpus.py`：記録から21段落を作ります（`corpus.json`）。
- `harness/`：ライブ翻訳と同じ順で訳すプログラムです。`--preset` で、アプリに入った用語集そのものを使います。
- `runner.py`：1回ごとにllama-serverを起動し直して、`harness` を動かします。
- `compare.py`・`terms.py`：変わった文の一覧と、用語の数です。
- `runs/`：結果です。名前は「モデル（`8b`・`08b`）-入力（`corpus`・`probe`・`general`）-条件」です。条件は次のとおりです。
  - `A`・`A2`：用語集も文脈もなし（今のアプリ）
  - `C1`・`C3`・`C4`・`C5`・`C6`：文脈だけ（`cand/c*.txt`。`c3` は分数を小数で書くよう頼む文で、効きませんでした）
  - `G1`：最初の候補（`cand/g1.tsv`）。`G1C1` などは文脈あり、`G1F1C1`・`G1F2C1` は分数の行を足したもの
  - `v2a`〜`v2d`：`cut`・`hike` の行の有無を変えたもの（分数の行を含む）
  - `V3`：31語（`cand/v3.tsv`）。`V3C1`・`V3C4`・`V3C6` は文脈あり
  - `V4`：入る30語（`cand/v4.tsv`）、`PRESET`：アプリに入った30語（`--preset`）
- `cand/`：試した用語集と文脈です。
